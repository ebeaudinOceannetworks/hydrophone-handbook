9. Data Access

This page is about how to get hydrophone data. For what each file type contains, see Data Products.

Which method to use?

There are threee ways to get the data: two of them inside ONC data portal Oceans3.0, plus one using ONC API.

The Hydrophone Viewer is for browsing the pre-generated 5-min spectrograms, and quick downloads to any format including audio. It is best for a first look, or sound hunting through visualizing the data. Use this when you want to see the soundscape before you download files.

Data Search is useful for when you want to download more than a few files at a time, whereas the Hydrophone Viewer allows for a single file at a time. Whether it is a few hours, or even 1 day of data from a particular location. There are a lot more user options that can be set through that interface.

Use the ONC API when you need more than a handful of files, or a data product with specific settings.

  • Hydrophone Viewer
  • Data Search
  • ONC API (advanced)

1. Log in to Oceans 3.0

Visit https://data.oceannetworks.ca and sign in with your ONC account.

2. Select Hydrophone Viewer

3. Choose a location or a hydrophone

From Hydrophone Viewer, a list of locations will appear on the left panel, under Hydrophone Data Search.

Pick a location. Go down the tree until you can select a device. Note that each hydrophone has a dedicated device code, which are often a combination of their manufacturer/supplier and a serial number (ex: Ocean Sonics icListen HF Hydrophone 1251).

The deployment window of each device is listed at the bottom. This information is important, as you will not be able to find data outside of the deployment window. If there are multiple devices under a location, the deployment windows go from top to bottom in chronological order. The most recent hydrophone in the water at this site is the last one of the list.

For hydrophone arrays, hydrophones are under Hydrophone A, B, C or D.

Navigate to Hydrophone Map page to find past and current deployments.

4. Choose a date

The date is in the following format: 01-Jan-2026. If a message pops up saying No Data, it either means the selected date is outside the deployment window, or the hydrophone did not record that day due to some issues.

5. Inspect the spectrogram

Each spectrogram is a visual representation of the soundscape over a 5-min time window. You can click on a spectrogram and it will size up.

6. Data download

When you want the underlying data (FLAC, MAT, PNG, …), you can select a spectrogram by checking the box underneath it.

In the window at the bottom, select a file format (select FLAC for lossless compressed audio file), and hit Request Data. This can take up to 2 minutes for larger files. Once the request has been completed, “Processing Request” becomes a Download that you can hit to retrieve your file.

You can request multiple files at once.

1. Log in to Oceans 3.0

Visit https://data.oceannetworks.ca and sign in with your ONC account.

2. Select Data Search

3. Choose a location or a hydrophone

From Data Search, a list of locations will appear on the left panel, under Data Source Selection. If you already know the device code (ex: Ocean Sonics icListen HF Hydrophone 1352), there is also the option to Sort by: Instruments by Category and jump to Hydrophone.

Pick a location, or a hydrophone.

4. Go to data source

The window pops up showing all information related to the hydrophone(s) at that location. Click on Select This Data Source.

5. Select the data product

This page is where to select the data products needed from this location. Set a Date From and Date To in the upper left. Use the visual green overlay to the right to know about data availability for this specific location.

Certain hydrophones (mostly Ocean Sonics) have ancillary data, such as acceleration, internal humidity, temperature, etc. Most likely, the data you are interested in rather lies in the audio format or derived spectral data. You can select a data product by simply checking the box underneath. For each data product, several formats are available, such as pdf, .mat, .txt, etc.

6. Select the product options

Most data product orders can also be customized through the Data Product Options panel below.

7. Add to cart

When you are satisfied with your order, do not forget to Add to Cart. This simply adds the product to the cart, which you can find in View Cart in the top right.

Go to Cart to trigger the creation of the order, which may take from seconds to minutes depending on the amount of data requested.

1. Get an Oceans 3.0 API Token

Visit Oceans 3.0 profile (Web Services API tab).

2. Install the ONC API package

  • Python: in the terminal, type pip install onc
  • MATLAB: use the Ocean Networks Canada MATLAB Client Library

3. Archive or order data product?

  • Archive: files that already exist on ONC’s disks, like raw audio files, pre-generated spectrograms, or instrument logs. Files are archived almost near-real-time. Downloading using this option is usually much faster.

  • Order data product: Oceans 3.0 can build a new file for you, with several options to pick from, including resampled audio files or a spectrogram with your own colour limits or frequency range. Depending on the request, it can take anywhere from a minute to several hours. HSD2 is only available this way: each file is generated from the source audio, and it is not in the pre-generated archive.

A simple rule: if an existing file would do, use Archive.

4. Select a location or a device

Requests are filtered by location (locationCode, always with deviceCategoryCode = HYDROPHONE) or by device (deviceCode). Location follows whichever instrument was deployed there; device follows one specific instrument across its deployments.

Visit the Hydrophone Map page to find location or device codes of past and current deployments.
